## Rules

- Pin the source commit before copying.
- Prefer reimplementation using max&gym Material UI components.
- Do not copy server actions, authentication, database, payment, advertising, premium, email, leaderboard, or social code from Workout.cool.
- Do not copy Workout.cool videos or images without a separate media-licence review.
- Add a row in the same pull request as the reused code.
- Add or update the appropriate notice in `THIRD_PARTY_NOTICES.md`.
