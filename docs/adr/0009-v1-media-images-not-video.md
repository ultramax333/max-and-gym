# ADR 0009 — Version 1 uses two-position images, not exercise video

- Status: Accepted
- Date: 2026-08-05

## Decision

Reviewed seed exercises use local start/end images. Custom exercises support one image. Video is deferred.

## Consequence

Lower licensing, storage, cache, performance, and offline complexity. Motion explanation is less rich but instructions and two frames cover version-1 needs.
