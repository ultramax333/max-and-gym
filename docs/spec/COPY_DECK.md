## Error tone

Errors are factual and actionable:

- `The set could not be saved. Your previous data is unchanged.`
- `The database could not be opened. Do not clear browser data. Open Diagnostics for recovery options.`
- `This backup is invalid or incomplete. No data was changed.`
- `A new version is ready. Update after this workout.`
- `Storage is running low. Export a backup and remove unneeded photos.`

Avoid apology, blame, medical claims, or vague text such as `Something went wrong` without an error identifier.
