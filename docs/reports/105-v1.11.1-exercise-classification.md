# v1.11.1 — Muscle and equipment classification

## Request, evidence and scope

Task 90, authorized FIX after the September 8 diagnostic; FM-39. The owner reported
upper-body exercises in Glutes and incorrect apparatus groups. Root-cause report:
`docs/reports/incidents/2026-09-08-classification-root-cause.md`.

Before editing, an isolated regression probe reproduced five failures: triceps
kickback treated as a hinge, incompatible generic alternatives, unrestricted
preferred alternatives, band exercises tagged Other, and a missing bench station.
A separate 100-seed quick-Glutes generation probe did not reproduce upper-body
initial selection; the confirmed route was alternatives/library classification.

## Changes

- Audit all 302 retained catalogue records with structural muscle/movement and
  named-equipment invariants; apply 16 explicit, reasoned overrides. Same IDs,
  273 generator-eligible records, unchanged media/licences; no catalogue expansion.
- Correct triceps/calf isolation movement roles, Pushups and abbreviated incline
  press; correct cable hip adduction primary muscle and the pinned instruction typo.
- Correct bands, bodyweight and multi-equipment requirements. Cumulative resistance
  tags prevent a band-assisted pull-up from appearing without both enabled choices.
- Add auxiliary setup stations (pull-up bar, dip support, step, ball, etc.) and missing
  benches. Keep machine seats distinct from separate benches and preserve whole
  supersets when ordering stations.
- Centralize target/eligibility/exclusion/equipment logic for alternatives. Filter
  before ranking saved suggestions; recheck and use fresh metadata at confirmation.
- Persist selection constraints for new generated workouts, including saved generated
  programs. Reload and complete-backup restoration preserve them. Legacy/manual
  sessions explain when no equipment availability was saved.
- Default Library muscle filter to primary muscles; expose an explicit secondary
  muscle checkbox and missing muscle/equipment filter entries.
- Resolve current reviewed equipment when preparing a new session from a saved plan,
  without rewriting the original plan or historical session snapshots.
- Corrected isolation roles exposed an under-budget 60-minute arm fixture. The quick
  planner can fill existing exercises within its existing 2–5 working-set range,
  retaining recovery/repetitions and enforcing the 90–110% duration bounds.

Files: catalogue builder, override data, catalogue/selection domain and tests,
generator constraints/quick planner, workout snapshot/repository/equipment modules,

## Compatibility, limitations and rollback

Application 1.11.1; exercise seed reviewed-7; generator deterministic-v10.
Schema 8, export 2 and cache 9 unchanged. The optional unindexed workout constraint
field needs no IndexedDB index migration. Old backups/sessions remain readable;
new backups preserve it. No personal-data reset or historical rewrite.

Auxiliary support is displayed rather than a redesigned selectable gym inventory;
availability constraints cover resistance tags. Existing sessions lacking those
constraints cannot retrospectively recover the user's original equipment selection.
The invariant audit catches known metadata failures, not every biomechanical nuance
or individual suitability issue. Other September 5 findings remain separate scope.

The local override reasons are based on pinned source instructions; cable adduction
was cross-checked against ACE's standing hip-adduction reference linked in the data.
No donor code, remote media or third-party prose was imported.

Rollback: revert the corrective commit through a new PR, then publish a higher
Android versionCode and a **newer exercise-seed identifier** so installed reviewed-7
records are refreshed. Historical data needs no reverse transformation.
