# Checkpoint and audit reports

Codex writes reports here.

Naming:

```text
00-...
01-...
...
08-...
```

Every checkpoint requires:

- audit report(s);
- checkpoint report based on `docs/templates/CHECKPOINT_REPORT_TEMPLATE.md`;
- evidence paths;
- exact commits/commands;
- status.

Do not delete prior reports. They form the regression timeline.
