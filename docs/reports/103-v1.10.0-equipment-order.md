# v1.10.0 — Equipment colours and pre-session ordering

## Audit and plan

- Task 06 extension; acceptance coverage: AT-M01, AT-E01, AT-E06, AT-E10, AT-K01–K04.
- Previous behavior: quick generation grouped only the first equipment tag. Bench requirements were absent from these tags; starting a saved/generated workout immediately created the session.
- Target: named equipment colours throughout the modern library/generator/workout UI, with a pre-start priority order that can put bench exercises first.
- Scope: pure station classification/sorting, shared setup route, existing modern start entry points, persisted session-only station snapshot, tests and release identity.
- Existing local audit output, APKs, source archives, and unrelated files were not included in this change.
- This branch is based on the still-open v1.9.0 proposal (PR #23, `16d6191`). It does not merge or modify that proposal.

## Implemented behavior

- `equipmentStations.ts` maps generator equipment tags to a shared palette and adds reviewed bench requirements using stable catalogue IDs. A machine bench press is not a free bench; preacher benches remain distinct.
- Bench metadata was checked against the local catalogue setup/execution instructions. Standing-or-seated optional variants do not automatically require a bench. Unknown/custom equipment remains explicitly labelled Other equipment.
- Equipment metadata is separate from generation availability constraints: Bench + Dumbbells remains both requirements, never a substitution of one for the other.
- Setup shows reorder buttons and a live exercise list. Exercises requiring several items follow the earliest matching station. Each exercise appears once; ties are stable.
- Superset/triset/circuit blocks move together, preserving group sequence and prescriptions. An original-order option and a priority-lift advisory are available.
- Generated sessions, saved sessions, active program starts from Home/Training, program details and the five-exercise arms preset all enter setup.
- The two-exercise Essential workout still starts directly: both exercises use the same dumbbell station, so there is no equipment order to choose.
- Cancel/back from setup leaves an existing session active. Replacement only happens after the final Start workout confirmation. A changed active-session identity is rejected rather than replacing a different session.
- Critical start remains transactional/idempotent through the existing service; double taps are guarded and retries reuse the operation ID.
- Active-session recovery preserves the selected sequence and station. Substitution clears the previous station assignment and uses the replacement's requirements.
- Badges use text plus colour in the library, generator/alternatives, active exercise, horizontal rail and workout plan.
- Android's setup fallback Back target is Training, not exit.

## Limits and rollback

- Station categories are not individual physical machines. The user still needs the compatible bench angle, rack or attachments shown in the exercise instructions/photos.
- Custom exercises with no setup metadata cannot have bench requirements inferred reliably.
- The equipment order is chosen per session, not saved as a global preference. A setup draft without a started session is not a new persistent record.
- Existing Switch here / Do later controls remain available during training; this change does not reorder an already-running workout automatically.
- Revert this feature commit to remove the setup route/colours. Existing snapshots remain valid; older code ignores the optional station field. No user-data rollback is required. Publish a higher build/cache identity for any released rollback.
- No donor code or third-party assets were copied.
