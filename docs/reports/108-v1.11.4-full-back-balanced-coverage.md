# v1.11.4 — Full-back bench extension and balanced sets

## Task and requirements

Task 06 (`GEN-003`, `GEN-007`, `GEN-011`, `GEN-015`) and `AT-M06`. Owner request on 2026-09-16: make the lower-back bench extension visible in Full back sessions and add a set to the least-used back muscles. This checkpoint is stacked on open PR #28; it neither merges nor deploys any preceding checkpoint.

## Audit and root cause

The reviewed catalogue already contains **Hyperextensions (Back Extensions)** with two local images, primary muscle `lower back`, equipment class `other`, and the reviewed `Back-extension bench` station. It was eligible for Full back, but the generic per-muscle ranking could choose Barbell Deadlift as the only lower-back coverage exercise. The duration loop then stopped once the time floor was reached and distributed later fill sets by per-exercise set count rather than by back-muscle coverage. No catalogue, media or equipment-station addition was required.

## Implemented behavior

When all gym equipment is available, the Full back quick-session generator now reserves Hyperextensions (Back Extensions) as its direct lower-back anchor. The preview therefore exposes its two existing local images and Back-extension bench badge. Equipment availability, explicit exclusions and Never Suggest are evaluated first: when `other` is unavailable or the exercise is blocked, it is not forced and another coherent Full back plan is generated.

After selecting the exercises, Full back generation calculates planned working sets for middle back, lats, lower back and traps. If the 110% duration ceiling permits it, one additional working set is assigned to a selected exercise covering one of the least-represented primary back muscles. Any remaining time-fit additions use the same least-covered-first order. The rule retains the existing two-to-five-set range, recovery value and 90–110% duration tolerance. It does not affect Upper back, strict Lower back, Lower back + supporting work or other body areas. The explanation shown below the exercise identifies the anchor and the balancing set.

## Accessibility, limitations and rollback

The station is rendered as existing text plus colour, so the status is not colour-only. Existing local images retain reviewed alternative text. No new touch control or horizontal layout was added. The anchor is intentionally skipped when the user disables `other` equipment or marks it Never Suggest. The balancing set is added only when it fits under the duration ceiling; the generator will not overrun the chosen session simply to add volume.

Rollback is a revert of this feature commit and restoration of v1.11.3 / deterministic-v12. No migration, database reset, cache clear or user-data operation is needed.
