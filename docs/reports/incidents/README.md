# Incident reports

Root-cause reports created by Task 90 live here.

Naming:

`<YYYYMMDD>-<short-id>-root-cause.md`

Rules:

- no personal workout values or media;
- no machine secrets;
- link to redacted artifacts rather than committing unsafe logs;
- distinguish evidence from inference;
- keep the report after resolution as regression knowledge;
- update `docs/spec/KNOWN_FAILURE_MODES.md` when a new failure class is confirmed.
