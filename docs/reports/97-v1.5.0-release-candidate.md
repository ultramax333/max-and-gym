# Max & Gym 1.5.0 release candidate

Date: 2026-08-14

Scope: publish the accepted focused-glute catalogue checkpoint with a unique semantic application version and signed Android update identity.

## Included checkpoint

- `13a9674` — focused Glutes catalogue and replacement expansion, accepted through PR #18.

## Release impact

- application version: `1.4.0` to `1.5.0`;
- exercise seed: `fedb-b0eed061e1c8-reviewed-4` to `fedb-b0eed061e1c8-reviewed-5`;
- database schema, export format, program seed, generator and cache identity: unchanged;
- Android application ID and signing contract: unchanged;
- runtime network origins and local-first data model: unchanged;
- no production dependency added;
- four pinned and locally bundled Free Exercise DB images added.

## Candidate validation

The release candidate must pass the full quality gate, production web build and route smoke, accessibility and performance audits, Android web bundle smoke, Gradle debug unit tests and debug APK assembly. Pull-request workflows repeat the quality, browser-matrix and Android gates.

After acceptance and merge, the trusted `master` workflows assign an Android `versionCode` above the previous release, build and verify the signed APK, publish GitHub Release `v1.5.0`, include the installer in the Pages artifact and run the deployed release-identity smoke.

## Data safety and rollback

No database or backup migration is required. The seed update is isolated from user exercise preferences. Before update testing, retain a current `.maxgym` backup outside app storage and install over the existing application without uninstalling it.

After publication, corrections require a new semantic version and higher Android `versionCode`; the signed `v1.5.0` release asset must not be replaced.

## Publication boundary

Repository policy forbids the release author from merging their own pull request. Publication stops at a verified release PR. Production deployment and signed APK publication begin only from the accepted merge to `master`.
