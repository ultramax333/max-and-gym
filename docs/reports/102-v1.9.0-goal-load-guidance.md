# Max & Gym v1.9.0 goal-based load guidance

## Scope

- Goal-specific repetition and RIR guidance for strength, hypertrophy and endurance sessions.
- Local load ranges calculated from up to three recent completed sessions.
- Visible calibration, confidence and load guidance in the quick-session preview and active workout.
- Optional `Use suggested` action; no automatic progression or forced load change.
- Goal context preserved for generated weekly programs as well as quick sessions.

## Calculation contract

- The generator remains the source of the repetition range and target RIR.
- Weighted working sets only are eligible evidence; warm-up, drop and bodyweight-only sets do not create an absolute kilogram recommendation.
- The local estimate uses Epley with repetitions in reserve: `e1RM = load × (1 + (repetitions + RIR) / 30)`.
- The median estimated one-repetition maximum is converted back to the selected repetition range and rounded to the nearest `0.5 kg`.
- Missing RIR or high-repetition evidence lowers confidence.
- A saved manual default load remains the highest-priority workout target.
- Without suitable history the interface requests a conservative calibration set instead of inventing a load.

## Data and privacy impact

- No database migration, reset, cloud call or new external origin.
- Existing workout sets and RIR values are read locally; no personal values are logged or exported by this feature.
- Existing programs and sessions remain compatible.

## Known limitations

- Load advice is an estimate, not a guarantee; machine increments and exercise technique can require manual adjustment.
- Bodyweight exercises receive repetition/RIR guidance but no invented kilogram range.
- Advice quality improves only when completed working sets include an honest RIR value.
- Manual load defaults intentionally override calculated advice at session creation.

## Rollback and recovery

- Revert the pull-request commit to remove the calculation and interface guidance.
- No data rollback is required because the schema and stored workout records are unchanged.
- A forward fix can adjust the pure formula or confidence thresholds without migrating user data.

## Release gate

- Pull-request quality, Chromium and Android checks must pass on a clean CI install.
- Merge requires fresh explicit approval for the exact pull request and head commit.
- After merge, the signed APK and its ZIP companion are produced by the existing Android release workflow.
